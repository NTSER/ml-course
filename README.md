# Supervised learning in motion

Three interactive HTML lessons for students.

**Course website:** https://ntser.github.io/ml-course/

## Update a lesson

1. Open this repository on GitHub.
2. Choose **Add file → Upload files** and upload the updated HTML file using the same filename.
3. Commit the change to `main`. GitHub Pages republishes automatically; allow a few minutes.

Keep `index.html` as the homepage. Its links point to the three original lesson filenames.

## Hosting

GitHub Pages publishes from the root of the `main` branch. `.nojekyll` allows the HTML files to be served directly. All lessons are self-contained.
